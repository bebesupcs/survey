# 베베숲 고객 경험 설문

고객용 설문: `/` · 관리자: `/admin`

## 관리자와 Google 연결
- `ADMIN_EMAIL` 환경변수에 사이트 관리자의 ChatGPT 로그인 이메일을 설정합니다.
- `GOOGLE_BRIDGE_SECRET`은 Sites 비밀 환경변수로 관리합니다.
- 관리자 화면에서 안내에 따라 Google Apps Script를 배포한 후 웹 앱 URL을 연결합니다.
- 연결 확인 전에는 실제 제출이 비활성화됩니다. 브라우저에 실제 저장 확인을 받은 후에만 완료를 표시합니다.
- 지정 스프레드시트에 `베베숲_응답`, `베베숲_문항사전` 탭을 만듭니다. 원래 탭은 수정하지 않습니다.
- 연락처는 Google Sheets에만 저장합니다. 인터뷰·혜택 제공이 모두 종료되면 `scheduleContactDeletion`을 실행해 29일 후 이름과 연락처를 삭제합니다. 다운로드한 사본은 별도 관리합니다.
- 비동의·인터뷰 미참여자는 연락처를 전송하지 않습니다.

## 질문 수정
관리자에서 질문 문구, 일반 선택지, 필수 여부를 편집합니다. 고객 유형과 조건부 분기에 쓰이는 선택지는 잠겨 있습니다. 최대 선택 수·문항 번호·분기 로직 변경은 소스 수정이 필요합니다. 기존 설문 세션은 시작 당시 버전으로 제출합니다. 원문에 명시되지 않은 조건부 필수 여부는 선택 문항으로 처리했습니다. Q4·Q5의 미정인 타 브랜드 목록은 관리자에서 추가할 수 있습니다.

## 검증
- `node survey.test.mjs`: 여섯 고객 유형, 조건부 분기, 동의 거절 시 데이터 제거, 유효성 검사, Google 브리지 가상 저장과 중복 방지, 개인정보 삭제.
- `node api.test.mjs`: 실행 중인 로컬 사이트에서 공개 문항, 관리자 접근 거절, Origin 검사, 필수값 누락 검사.
- `npx tsc --noEmit`, `npm run build`.
- 로컬 D1 스키마는 생성된 Drizzle 마이그레이션을 적용합니다. 운영 스키마는 Sites가 적용합니다.

## 아직 외부 확인이 필요한 사항
실제 Google 계정 권한과 Apps Script 연결은 소유자의 최초 설정이 필요합니다. WebMCP 지원 실행 컨텍스트가 없어 런타임 도구 등록은 검증하지 않았습니다. 질문 입력용 도구를 제공하지만 제출하지 않습니다. 고객에게 배포하기 전 Sites 접근 범위를 공개로 변경해야 합니다.
