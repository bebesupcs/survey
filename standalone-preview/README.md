# 🍼 베베숲 고객 경험 설문 프로젝트

기존 GPT 사이트(`https://bebesup-customer-survey.naverbingo.chatgpt.site/`)의 디자인, 문항, 조건부 분기 로직을 100% 온전하게 복원하고, 수정과 확장이 쉽도록 모듈화하여 제작한 프로젝트입니다.

---

## 📁 파일 구성 안내

1. **`index.html`**:
   - 설문 전체 구조(상단 로고 탑바, 좌측 스텝 안내, 설문 카드, 푸터)를 담고 있는 메인 웹 파일입니다.
   - **이 파일을 더블클릭하시면 크롬/엣지 등 웹 브라우저에서 바로 실행**됩니다. (별도 서버 설치 불필요)

2. **`questions-data.js` (문항 및 설정 편집용 파일)**:
   - **질문 내용, 선택지, 필수 여부, 최대 선택 개수, 힌트 문구, 경품/개인정보 동의 안내문**이 아주 깔끔한 한글 형태로 정리되어 있습니다.
   - 메모장이나 VS Code 등 원하는 에디터로 열어서 글자를 바꾸기만 하면 즉시 설문에 반영됩니다!

3. **`style.css`**:
   - 베베숲 고유의 차분한 포레스트 그린 컬러(`--primary: #087768;`)와 아이보리 톤의 카드 디자인, 모바일 반응형 디자인이 적용된 스타일시트입니다.

4. **`app.js`**:
   - 문항별 스마트 분기 로직(베베숲 사용 여부에 따른 Type A/B/C/D 분기 등), 유효성 검사, 진행률 계산, 전화번호 자동 포맷팅, 로컬 자동 저장, 설문 완료 후 JSON 결과 확인 및 다운로드 기능을 담당합니다.

5. **`bebesup-logo.png`**:
   - 원본 사이트의 베베숲 정품 로고 이미지입니다.

---

## 🛠️ 수정하는 방법

### 1) 말로 수정 요청하기 (가장 편함)
대화창에 언제든지 아래처럼 말씀해 주시면 제가 바로 코드를 수정해 드립니다:
- *"Q3 질문에 '2주 이상' 선택지 추가해줘"*
- *"경품 당첨 인원을 50명에서 100명으로 바꾸고 상품권으로 바꿔줘"*
- *"Q18에서 '가격이 왜 다른지' 항목 삭제해줘"*

### 2) 직접 파일 열어서 수정하기
- `questions-data.js`를 메모장이나 에디터로 엽니다.
- 원하는 문항 번호(예: `Q1`, `Q2` 등)를 찾아 따옴표 안의 글자를 수정하고 저장합니다.
- 브라우저를 새로고침(`F5`)하면 바로 반영된 모습을 확인하실 수 있습니다.
